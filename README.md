# PHP CLI Calculator

A command-line calculator built with vanilla PHP as part of a backend engineering curriculum.

## Features
- Supports addition, subtraction, multiplication, and division.
- Handles user input interactively via CLI.
- Includes robust error handling for division by zero.

## Installation & Usage
1. Ensure PHP is installed on your machine.
2. Clone or download this repository.
3. Run the calculator script:
   ```bash
   php calculator.php
